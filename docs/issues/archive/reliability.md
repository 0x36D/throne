# 模拟可靠性（BUG-0003 / 0004 / 0006）

状态：完成，2026-09-21。

根因：Demo F 宣告三个可选能力却只实现一条；场景 reducer 对未知事件静默返回原状态。payload 读取把损坏值变为空集合。网页 catch 丢弃原因，初始化失败又被加载条件遮蔽。

范围：显式处理未知事件；补齐证据处置、不可达命令失败；共享严格 payload 读取；网页错误及重开。避免全项目事件泛型重构。

验证：分别检查每个合法证据处置的实际后果；未知事件及畸形必要字段失败；不可达行动保留失败状态；原始/重放一致；网页失败可见且能重开。

结果：新增回归覆盖交给丞相的消息与观察、隐藏处置、七个场景及 bootstrap 的未知事件、坏数组/对象、不可达行动失败以及无会话时的错误详情和重开按钮。决策评分与因素数组的损坏也会显式失败。初次修复时 46 项测试通过，类型检查和构建通过。使用共享严格字段读取，未重写全部事件协议。

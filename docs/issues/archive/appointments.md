# 职位与任命（FEAT-0004）

状态：完成，2026-09-21。现行规则见 [ADR 0003](../../architecture/0003-appointment-layer.md)。

当前差距：固定职位字符串和手写正式权威不能表达一次真实换职，也没有任命/结束/争议历史。

方案：新增共享职位与任命契约；通过事件执行任命、认可和结束，派生正式指挥权。增加“将军升丞相仍受旧部服从”场景，包含继任统领、延迟冲突命令、实际行动及回报，提供双语查看。

验证：履历延续、私人关系不变、越权及同时超额主张、认可、免职、失败引用、关系变化能改变服从、信息隔离与确定性重放。

结果：8 项任命规则测试和双语界面的信息隔离回归通过；真实浏览器验证回报、管理员履历与中文/英文切换。网页提供“职位与任命”机制演示；越权与超额操作目前由规则接口及测试覆盖，尚未做成玩家操作菜单。

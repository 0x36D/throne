# FEAT-0005：连续决策短局

状态：完成，2026-09-22。现行规则见 [ADR 0005](../../architecture/0005-continuous-crisis.md)。

单轮接入尚不能验证人物经历是否影响后续判断。本次实现同一世界、同一统领的两次决策：首轮回报后送达新情报，玩家维持已知驻地或重新部署；统领获得自己实际经历的命令、行动和可见回报，不读取全局真相。既有命令及其后果保留。

新增连续场景，不替换机制演示的单轮模型。存档版本区分新旧场景；失败按决策节点重试，带 episode id 的请求避免上轮重复点击被当作下轮命令。复盘在整局结束后开放，界面中英双语并显示统治者可见时间线。

验收：72 项测试通过，类型、格式、构建通过。新增测试覆盖实际后果、前情/新情报输入差异、传递延迟与信息隔离、第二轮失败恢复、重复提交、旧存档与整局无模型重放。可控策略测试证明前情或新证据的变化能传到后续行为；这不等于证明真实 LLM 必然使用每条记忆。

浏览器实际完成两局，共四次官方 DeepSeek thinking/high 调用，四次均观察到 thinking；每局 16 个提交事件，复盘和无模型回放通过，开发服务重载后可恢复完成记录。中英切换已人工检查。

第一局 `9e51b67b-907f-4705-87b4-4d7c053dcbf2`：先守宫，再赴东门，两次遵命，宫城和仓场分别保住。两次调用约 5.1 / 3.6 秒，reported total tokens 1779 / 2740。第二次简短理由引用了最新圣旨、新的东门情报和此前宫城受到保护的报告。

第二局 `8e5ab223-8835-4322-971e-11441a489d7d`：先赴东门，再维持东门，两次遵命；第一轮宫廷档案库失守，第二轮仓场守住，旧损失没有消失。两次调用约 4.5 / 2.9 秒，reported total tokens 1807 / 2599。第二次输入确实含不同的自身行动记忆与宫城失守报告，但简短理由主要讨论最新军情和抗命风险，不能断言旧损失改变了其判断。

行为局限：四次均服从，样本不足以校准政治行为；有的理由直接引用动机数值或把丞相称作“总理大臣”，叙事还不自然。下一步宜比较不同证据、恩主支持和惩罚风险，而非用提示词强迫抗命。试跑者知道场景设定，不是盲测。完整存档留在 gitignored runs/，无原始思考链。

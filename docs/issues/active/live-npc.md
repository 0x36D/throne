# FEAT-0001：真实 DeepSeek 军官

状态：实现中。用户授权接入并由 agent 以玩家身份实玩一轮。

差距：当前玩家命令由固定规则执行；Harness 适配器未用于游戏请求，没有本地服务、持久回放或调用失败恢复。

方案：在现有玩家场景的收令与执行之间加入 NPC 决策。军官同时收到皇命与保护军饷署的丞相命令，根据自身信息选择遵从其中之一。模型不读取隐藏危机结果。离线演示保留；新入口明确调用 DeepSeek。服务只监听本地，同源 POST；密钥只由服务读取。

验证：NPC 不接收真相；两条合法选项各自产生世界后果；无效输出和超时不提交决策；重试保留玩家原令且不重复已提交事件；记录重放不调用模型；API 不提前暴露管理数据；真实浏览器下一次圣旨并记录实玩结论。

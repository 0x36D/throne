# 工作事项

登记条件和工程规则见 [AGENTS.md](../../AGENTS.md)。这里仅保存当前事项及历史索引，不重复规范。

[BUGS.md](BUGS.md) 与 [FEATURES.md](FEATURES.md) 是短索引；活动事项放在 `active/`，记录动机或现象、根因或当前差距、方案和验证。状态用“待调查 / 已确定 / 实现中 / 完成 / 暂不处理”即可。登记不要求把正常工程选择送回审批。

事项完成后，调查和验证移入 `archive/`，从活动索引移除。历史目录按需追溯，不在日常开发启动时遍历。已生效的设计继续放在 `docs/architecture/`，不能随实现任务一起归档。

文档职责和阅读入口见 [docs/README.md](../README.md)。原始 PR #2 的六项意见及取舍见 [review 记录](archive/pr-2-review.md)。

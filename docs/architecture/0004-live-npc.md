# ADR 0004：本地真实 NPC 与可重放记录

状态：采纳，2026-09-21。

Vite 的本地服务插件提供 /api/live 接口，仅用于本机原型。浏览器只发送玩家选择和语言，不持有 provider 密钥。开发服务绑定 127.0.0.1，拒绝跨站写入；禁止开发服务器直接提供 secret/、runs/ 和 .dsh/ 文件。静态 build 本身不具备模型调用能力。Vite 使用 configLoader runner 以加载工作区 TypeScript 服务模块。

最初单轮版本沿用玩家场景：皇命 t=45 抵达后军官开启决策，t=50 调用策略，t=60 执行，t=90 回报。现行两次决策场景与 version 2 存档见 [ADR 0005](0005-continuous-crisis.md)，旧单轮存档继续支持。军官只获得自己的身份、动机、已收到的皇命及丞相命令、局部情报与关系；客观宫城渗透状态不传给模型。丞相要求保护军饷署，皇命目标由玩家选择。两个可用能力均由引擎实现。

Harness 固定版本与 sdk-minimal 保留；专用 patch 禁用 shell 工具和会话落盘。thinking 显式启用 high，输出上限 4096，整次决策超时 90 秒。每次尝试创建隔离的运行目录和进程，结束时关闭；错误可见且只能由用户显式重试，不换 provider 或替角色决定。

同一局同一玩家选择只提交一次。模型失败时事务保持未提交，队列停在待决策事件；重试从该事件继续。决策后续执行失败不能重新生成已经提交的决定。

runs/ 下保存模型可见输入、结构化输出、简短理由、事件与实际结果；原始 reasoning 不落盘。provider/model 请求值与可观察到的返回值分开记录，无法取得的返回信息明确记为 null。完成后才可访问管理员复盘；普通状态接口始终只返回统治者信息。重放使用 reducer，禁用模型策略。

已完成的结果可从磁盘恢复；未完成局在服务内存中，重启会丢失。失败时统治者仍能看到自己发出的圣旨，但不会提前看到军官收令状态或私人决策。局号保存在当前浏览器标签页的 sessionStorage，可恢复该标签页最近的一局；历史列表尚未实现。

官方依据：[thinking mode](https://api-docs.deepseek.com/guides/thinking_mode/)，运行配置核对锁定的 dsh-sdk-minimal 与 dsh-sdk-client 包。
